### How to play
1. Clone this repository
2. Install `pygame-ce` with `pip install pygame-ce`
3. Run game.py, `python3 game.py`
---
1. Once the game is running, pick a map to race on.
2. As soon as the map is selected, your time has started.
3. Use the arrow keys to move your car and stay on the track.
4. Use space to drift and speed up your car on the turns!
5. Pass the finish line to end your time.
6. Race again!!
